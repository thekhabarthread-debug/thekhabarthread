# The Khabar Thread

Hindi news website powered by Cloudflare Workers and Static Assets, Firebase Authentication/Firestore, and Cloudinary.

## Included

- Server-rendered Open Graph and Twitter Card metadata for every news URL
- 1200×630 Facebook, WhatsApp and X preview images
- Self-referencing canonical URLs and complete NewsArticle JSON-LD
- Dynamic Firestore-backed sitemap
- Verified Google admin authentication
- Signed Cloudinary uploads through the Cloudflare Worker
- Cloudinary responsive image optimization
- Security headers and admin no-index protection
- Firestore rules with public reads and admin-only writes

Deployment instructions are in [DEPLOY.md](DEPLOY.md).
